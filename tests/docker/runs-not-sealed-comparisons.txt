# runs, declared so the artifact census can tell them from a run somebody wrote without sealing.
#
# The census's rule is: every directory under runs/ either carries flip.json + .sealed/mapping.json,
# or is named here. An allowlist in the tree is the stronger control precisely because adding to it
# is a tracked, reviewable edit — a marker file inside the directory could be written by the same
# thing that failed to seal.
#
# Two classes live here, and the distinction matters:
#
#   PRE-S6 RUNS  — real comparison runs taken before the seal existed (PITFALLS 71). Named by
#                  <before>-to-<after>, which is itself the disclosure S6 closed.
#   EVIDENCE     — directories that were never a comparison at all: a seam's working artifacts, a
#                  design copy, a drill. These have no arms to seal.
#

# declaring and there was no honest way to call a post-S6 drill a pre-S6 run. The list had already
